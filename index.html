Aplikasi Daftar Tugas Kuliah

Versi: 1.0.0

    Penjelasan Teknologi

    Git & npm: Git untuk version control, npm untuk manajemen package.

    TypeScript & Vite: Vite sebagai bundler dan dev server. TypeScript menambahkan tipe data statis ke JavaScript.

    Compiler vs Transpiler: TypeScript adalah transpiler (mengubah TS ke JS), berbeda dengan compiler yang mengubah kode ke bahasa mesin.
